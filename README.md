# 🚀 Luccane Baileys Mods

Custom WhatsApp Bot Base using Baileys

## ✨ Features
- Anti Spam (Delay System)
- Anti Limit (Queue System)
- Auto Reconnect
- Auto Session Reset
- Simple Command

## 📦 Install
npm install

## ▶️ Run
npm start

## 🔑 First Run
Scan QR di terminal

## ⚠️ Notes
